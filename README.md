# kaffka ( Java )

## Producer - send events to kaffka(bucket)
* strucutred ( organised )
* (Asynchronous),(Publish-Subscrib) Event Driven
* real time processing(Streaming API)
* distributed computing 
* Fault tolerant and High Performance
* highly scalable system for managing event logs
* Durable data log
* pull based (independent user can read) 

## Traditional message queue (RabbitMQ)
* (once used - deleted )
* push based- once consumed
* synchronous(wait-starvation-deadlock)
* tight coupling
* single point failure
* losing analytics data
